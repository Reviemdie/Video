# Video Cutter Pro

Десктопное приложение на PySide6 для нарезки и обработки видео с модульной архитектурой.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app/main.py
```

## Что реализовано

- Нарезка на равные сегменты с коротким последним фрагментом.
- Настройка FPS, скорости, ориентации, blur-фона для vertical 9:16.
- Подключение баннера (позиция, размер, прозрачность, анимация-параметр).
- Настройки AI-субтитров (UI + заготовка движка).
- Фоновая музыка с громкостью и fade.
- Рендер через ffmpeg с базовыми параметрами.
- Система пресетов: сохранить, загрузить, удалить, обновить, импорт/экспорт.
- Модульная архитектура (`core`, `ui`, `utils`).
